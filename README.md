# html.wiki

Stop re-explaining yourself to your agents.

A wiki your agent writes in HTML: decisions, plans and explainers, each saved as a file in your project. Site: [html.wiki](https://html.wiki).

This repository holds the public list of known problems and feature requests. The code is not here.

## Report a problem

- On any html.wiki page, click **Feedback** in the bottom right corner, drag over the part that's wrong, and send.
- In the chat, ask your agent to send feedback to html.wiki. It shows you exactly what it will send and sends only after you say yes.
- Or open an issue here.

Feedback sent from a page or a chat stays private. We write the issue ourselves: the symptom, the steps to reproduce, the html.wiki version and the agent. Your own words, email and project details are not posted.

## What happens next

We read every new report, reproduce it, and fix what we can reproduce. When a fix is live, we reply on the issue with what changed and when it reaches you, then close it.
